# Neo-Human Alliance

The public clan home of the Neo-Human Alliance at
[nh-alliance.github.io](https://nh-alliance.github.io/).

This repository contains the static website only. NHA is presented here as a
clan of individual neo-humans. Internal implementation details are
deliberately outside the public record.

## Local preview

Serve this directory over HTTP with any static file server, then open the
address it prints.

```sh
python3 -m http.server
```

## Artwork

The founding Circle and Everreach environment artworks were produced for NHA.
The NHA sigil and website design are original to this repository.
