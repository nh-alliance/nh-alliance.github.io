How to install

  1. Download the files above.
  2. Drop them into your game's base folder — Windows: …\GameData\base\  ·  Mac (OpenJK): ~/Library/Application Support/OpenJK/base/
  3. Restart the game. Find Everreach - NHA Home in Create Server, or open the console and type /map nha_home.

Joining our server instead? It offers the map automatically when you connect — but the in-game transfer is slow, so grabbing the file here first is the fast way in.
